Claude Codeとは

日本語で指示を出すと、PCを操作して作業を実行してくれるAIアシスタント。

💬

ChatGPT / Claude.ai

ブラウザ上で動作。質問への回答や文章生成が得意。いわば「賢い会話相手」。

⚡

Claude Code

自分のPC上（ターミナル）で動作。ファイル操作・データ分析・外部ツール連携まで実行。「実行力のある秘書」。

🤖

Claude Cowork

Claude Desktop（GUI）で動作。Excel/PPT作成、長時間タスク、クロスアプリ連携。「自律型ナレッジワーカー」。

Before / After：AI活用のビジョン

「作業者」から「意思決定者」へ — 人間の役割が変わる。

😓

BEFORE：便利な相談相手

人間が質問 → AIが回答 → 人間が自分で動く。
AIは「答える」だけ。動くのは全て人間。

例：売上傾向要約を依頼 → CSVが返る → 人間が転記して決算書作成

🚀

AFTER：優秀な社員

きっかけ発生 → AIが情報収集 → AIが思考 → AIが実行完了。
人間は「方向性を決める」だけ。実行は全てAI。

例：月末になる → AIがERP・銀行からデータ抽出 → 仕訳生成、決算書作成 → 承認依頼をSlack送信

インストールガイド

まずはアカウントを作成し、以下の手順でインストール。

事前準備: console.anthropic.com でAnthropicアカウントを作成し、claude.ai/pricing でプランに登録してください。

1

ターミナルを開く

Command + スペース →「ターミナル」と入力 → Enter

2

インストールコマンドを実行

Terminal
curl -fsSL https://claude.ai/install.sh | bash
3

Claude Codeを起動

Terminal
claude
4

ログイン

自動でブラウザが開くので、claude.aiのアカウントでログイン。
（ブラウザが自動で開かない場合は、ターミナルで c キーを押すとURLがコピーされる）

1

Git for Windowsをインストール（必須・先にやる）

gitforwindows.org からダウンロード → 「Next」→「Next」→…→「Install」でOK

2

PowerShellを開く

Windowsキー →「PowerShell」と入力 →「Windows PowerShell」をクリック
（「管理者として実行」は不要）

3

インストールコマンドを実行

PowerShell
irm https://claude.ai/install.ps1 | iex
4

Claude Codeを起動

PowerShell
claude
5

ログイン

自動でブラウザが開くので、claude.aiのアカウントでログイン。
（ブラウザが自動で開かない場合は、PowerShellで c キーを押すとURLがコピーされる）

エラーが出たら： スクリーンショットを撮って（Mac: Cmd+Shift+4 / Win: Win+Shift+S）、claude.ai に画像を貼り付けて「この画面で困っています」と聞くだけでOK。

12

まとめ

Claude Codeの3つのポイントと、社内での次のステップ。

1

日本語の指示だけで動く

プログラミング知識は不要。「こうしたい」と伝えるだけ。

2

実作業を代行してくれる

ファイル作成、データ分析、ツール連携を自動化。人間は意思決定に集中。

3

MCPで複数ツールを横断

Notion、Slack、Google系ツールなどを一度の指示で操作可能。

社内での次のステップ:
① まずはProプラン（月$20）で個人利用から始める
②「ちょっと面倒だけど、自動化するのはもっと大変そう…」という業務こそClaude Codeの出番
③ チームでの導入を検討する場合はTeamプランも選択肢に
